# A2：过程间符号分析

## 分析算法

见《过程间分析》课件的上下文敏感性分析部分。

你需要在上一个 lab 的算法中加入函数之间的依赖：具体来说，你需要将实参的抽象值合并到形参，将各个返回位置的抽象值合并后传回调用者。可以参考 [南大 Tai-e 作业 4 文档](https://tai-e.pascal-lab.net/pa4.html) 中过程间常量传播的部分（注意本次作业你不需要实现类层次结构分析，你也不必仿照该文档建立或调用 ICFG）。

在 Tai-e 中，你需要重点关注 `Invoke` 类。其中 `Invoke.getInvokeExp()` 提供静态调用表达式。你可以通过 `getMethodRef().resolve().getIR()` 获取被调用函数的 IR，通过 `getArgs()` 获取实参，通过 `Invoke.getResult()` 接收返回值的变量。其余方法调用请检查 Tai-e 相关文档或 API。

### 条件压缩函数

本次 lab 需要你额外实现简单的条件压缩函数。见《数据流分析：框架和扩展》课件的条件压缩函数部分。你需要为每个条件的两个后继分别计算抽象状态：条件成立时使用原命题，条件不成立时使用否命题。

| 条件 | 真分支中变量允许的符号 | 否分支中变量允许的符号 |
| --- | --- | --- |
| `x > 0` | `+` | `-0` |
| `x >= 0` | `+0` | `-` |
| `x < 0` | `-` | `+0` |
| `x <= 0` | `-0` | `+` |

例如 `if (flag > 0)` 的否分支使用条件 `flag <= 0`，因此 `flag` 的抽象值应当和 `-0` 取交。条件两侧都是变量时，需要利用两者当前的抽象值，同时压缩两个操作数。例如 `if (x <= y)` 的真分支中，若 `y` 为负，则 `x` 也必须为负；若 `x` 为正，则 `y` 也必须为正。交集为空时，该分支应当不可达。

## 完整例子

[MultiCaller.java](../handout/tests/a2/MultiCaller.java)

```java
package a2;
import benchmark.internal.Benchmark;
public class MultiCaller {
    static int negate(int x) {
        Benchmark.testSign(1, x);
        x = -x;
        return x;
    }
    public static void main(String[] args) {
        int x = negate(-3);
        int y = negate(0);
        int z = x + y;
        Benchmark.testSign(2, z);
    }
}

```

对应 .out：

```text
1: -0 .. -0
2: + .. +
```

针对第一个询问：由于有两次 `negate` 调用，$x$ 的取值可能为 $0$ 或 $-3$，因此此处输出 `-0`。针对第二个询问，两次调用分别将负和零传入各自的上下文，返回正和零，因此 $z$ 为正，输出 `+`。
