# A1：过程内符号分析

## 作业要求

本次作业希望你实现一个 Java 上的符号分析工具。具体来说，希望你计算每个程序位置上整数变量的抽象符号值。在 `Benchmark.testSign(id, x)` 处，输出执行该语句前 `x` 的分析结果。

分析使用下列抽象域：

| 抽象值 | 表示的整数集合 | 输出 |
| --- | --- | --- |
| 正 | 正整数 | `+` |
| 负 | 负整数 | `-` |
| 零 | 仅含 0 | `0` |
| 正零 | 非负整数 | `+0` |
| 负零 | 非正整数 | `-0` |
| 槑 | 全部整数 | `+-0` |

答案文件格式为 `id: L .. U`，L 为该查询的实际符号，U 为符号分析应当得到的结果。你的分析器应当针对每个询问语句输出一个符号，例如 `1: +0`。设 $\gamma$ 表示抽象值对应的整数集合，结果 $R$ 应当满足：

$$
\gamma(L)\subseteq\gamma(R)\subseteq\gamma(U).
$$

例如 `z = x - x` 针对 `z` 的标准答案为 `0 .. +-0`，输出 `0`、`+0`、`-0` 或 `+-0` 均被接受，输出 `+` 或 `-` 不被接受。

## 分析算法

见《数据流分析：示例》课件的符号分析部分和《数据流分析：框架和扩展》课件的工单算法部分。

本次作业主要目的是熟悉 Tai-e（或者你使用的其他分析框架）的分析方式。按照上述算法计算的结果构成标准答案的上界；更精确的分析结果也可以被接受。具体语法限制见“测试数据保证”一节。

## 完整例子

[SixSigns.java](../handout/tests/a1/SixSigns.java)

```java
package demo;
import benchmark.internal.Benchmark;
public class SixSigns {
    public static void SixSigns(int input) {
        int p=3;
        int n=-2;
        int z=0;
        int nonnegative;
        int nonpositive;
        int any;
        if(input>0) {
            nonnegative=p;
            nonpositive=n;
            any=p;
        } else {
            nonnegative=z;
            nonpositive=z;
            any=n;
        }
        Benchmark.testSign(1,p);
        Benchmark.testSign(2,n);
        Benchmark.testSign(3,z);
        Benchmark.testSign(4,nonnegative);
        Benchmark.testSign(5,nonpositive);
        Benchmark.testSign(6,any);
    }
}
```

你应当输出：

```text
1: +
2: -
3: 0
4: +0
5: -0
6: +-0
```

两个分支在查询前合并，所以 `nonnegative` 为正零，`nonpositive` 为负零，`any` 为槑。

## 测试数据保证

入口函数每个参数可以是任意整数。仅包含 `int` 参数和局部变量、赋值、`+ - * / %`、一元负号、整数比较、`if/else`、`while`、`break`、`continue`。条件分支和循环分别最多两层，无函数调用、对象、数组、对象域和 `args` 等等。

隐藏程序的可能变化范围见公开数据末尾的描述。
