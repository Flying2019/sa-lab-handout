# A5：符号分析与指针分析的组合

## 作业要求

本次作业希望你组合 A2 的符号分析和 A4 的指针分析，利用指针分析结果反向更新符号分析，得到更精确的分析结果。同时你需要进行数组扩展，针对数组的第一个位置建立变量，并在下标访问时使用符号分析结果判断是否访问的是第一个位置。你不需要更改符号分析的抽象类和指针分析的其他分析策略，仍然采用流非敏感、精确域敏感的规则，并用方法克隆策略处理上下文敏感性。

## 分析算法

本次作业希望你组合 A2 的符号分析和 A4 的指针分析，并进行数组扩展。

### 组合分析

本次作业仅要求你进行简单的组合分析：反复迭代运行两种分析，直到分析结果不发生变化。

由于指针分析采用的是非流敏感分析，所以符号分析结果对于指针分析的主要作用在于筛选出可达分支。你只需要针对符号分析判定可能可达分支中的所有语句重新运行指针分析，即可实现更精确的分析。符号分析结果还可能影响数组扩展，这一部分在“数组扩展”里介绍。

指针分析结果对于符号分析的作用在于：部分 int 变量来源于类内部，仅根据变量名称无法准确判定，需要根据指针分析结果来更准确地判断。你需要处理类之间关系来获得更精确的结果。具体来说，当读取 `x.n` 时，需要根据 `x` 的指向集合合并各对象的 `n`；在写入时，需要更新各个可能对象的 n。

具体来说，在符号分析的 CFG 基础上，你还需要维护类内部的 int 域之间的赋值关系。例如，你可以通过这些赋值关系添加额外的边，并在新的图中运行符号分析，求解不动点。

### 数组扩展

本次作业要求你针对数组的第一个位置进行数组扩展。例如 $a$ 是一个数组，那么你需要针对该数组建立两个变量 $a_0$ 和 $a_{>0}$。数组访问时，为了区分具体访问的变量，需要先根据符号分析得到下标的符号，以精确定位该次访问对应的变量。例如下标的分析结果是 $0$ 时，直接关联 $a_0$，结果是 $+$ 时关联 $a_{>0}$，是 $+0$ 时需要同时关联两个符号。数据保证不会出现负下标访问的情况。所以根据符号分析结果不同，指针分析的数组变量可能也会不同。

本次作业可能还涉及多维数组。但由于多维数组在 IR 上和一维数组没有太多区别，相同方式处理即可。

在这次作业中，你需要额外注意构造函数。该函数在 IR 中的名称是 `<init>`。类的 int 域默认拥有 0 初始值，**但若在相关读取发生前，能够确定已被覆盖，则不将 0 计入该次读取的结果**。

## 完整例子

[AliasBranch.java](../handout/tests/a5/AliasBranch.java)

```java
package a5;

import benchmark.internal.Benchmark;
import benchmark.objects.A;
import benchmark.objects.V;

public class AliasBranch {
    public static void main(String[] args) {
        Benchmark.alloc(1);
        V x = new V(1, 0);
        Benchmark.alloc(2);
        V y = new V(-1, 0);
        Benchmark.alloc(3);
        A a = new A();
        Benchmark.alloc(4);
        A b = new A();
        V z = x;
        int k = z.n;
        A p = a;
        if (k < 0) {
            p = b;
        }
        Benchmark.test(1, p);
        Benchmark.testSign(2, k);
    }
}
```

`V` 定义如下：

```java
package benchmark.objects;

public class V {
    public int n;
    public int m;
    public A p;
    public V q;

    public V(int n, int m) {
        this.n = n;
        this.m = m;
    }

    public int read() {
        return n;
    }
}
```

对应 .out：

```text
1: 3
2: + .. +
```

在这个样例中，可以分析出 `z` 指向 `x`，所以 `k` 符号为 $+$，并推出 `p` 指向 `a`。

你可以通过以下方式进行分析：初始时 $k=\bot$ 进行一次符号分析，将 `if` 分支设置为不可达；然后进行指针分析，得到 `z` 和 `x` 指向抽象地址 $1$ ，`p` 指向抽象地址 $3$，所以 `z.n` 的符号和 `x.n` 相同；然后再进行一次符号分析，得到 `k` 的符号和 `x.n` 相同，均为 $+$，`if` 分支仍然不可达，分析结束。
